# Recovered H5 game client

Original client downloaded from the H5 resource URL embedded in the user's APK:
https://cjjlqres.ruiruiyouxi.com/taptapReleaseRes/

The downloaded files are kept as GitHub Actions artifacts to avoid bloating the
Git repository with a large binary resource tree. snapshot-manifest.json
records file paths, sizes and SHA-256 hashes. The original APK remains unchanged.

This is the recovered original client, not yet an offline-patched build.
