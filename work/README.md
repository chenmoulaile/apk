# 工作目录说明

当前仓库已经包含恢复的 H5 客户端资源、离线逻辑补丁和 Android APK 构建/验收脚本。不要再沿用初始静态分析阶段“没有 H5 游戏源文件、没有可玩 APK”的旧状态判断。

## 目录

- `analysis/`：APK 静态分析、游戏协议和服务端端点研究；其中部分文档记录的是早期静态分析结论。
- `assets/`：离线补丁运行时需要的原版资源帧，例如 `zuan01.png`。
- `protocol/`：从客户端源码中确认的协议字段；未确认的服务端响应不能猜测。
- `recovered/`：恢复 H5 静态资源、图集和配置表的脚本。
- `tools/`：离线 H5/Android 补丁、构建辅助工具和断网模拟器回归脚本。
- `../com.ruirui.cjjlq.apk`：原始 Android 壳 APK。
- `../dist/`：工作流构建输出的签名离线 APK。
- `../tmp/`：解包、资源快照、中间文件和本地诊断输出，不提交。

## 仍需验证的功能

- 宠物普通升星、魂灵卡升星和进化位于 PR #7 的功能分支，只有独立断网模拟器回归通过后才能并入主分支。
- PvE 使用确定性的本地战斗模拟器，不是原服务器战斗算法的完整复刻。
- 排行榜、聊天、在线玩家互动、支付、广告、分享及在线服务不提供真实联网能力。
- 其他活动、副本和深层养成仍需逐项恢复并验证。

## 维护约定

1. 修改 H5/Android 运行逻辑后，先做 JavaScript 语法检查和静态验证。
2. 必须运行 `work/tools/test_offline_apk.sh` 对断网 Android 模拟器执行端到端验收。
3. 只有模拟器脚本实际输出 `OFFLINE_SCENE_TEST=PASS` 才能称为通过；APK 编译或签名成功不等于游戏可玩。
4. 构建说明在模拟器通过后才允许标记 PASS。
5. 历史分析文档中的“资源不存在”“没有构建测试”等结论只代表早期阶段；后续状态以提交记录和 Actions 验收日志为准。
